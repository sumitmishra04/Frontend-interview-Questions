Advanced React interview questions test a deep understanding of the library's internal workings, performance optimization techniques, and architectural patterns. Key topics often move beyond basic syntax to explore concepts like reconciliation, hooks behavior, performance trade-offs, and state management. [1, 2]  
Core Concepts & Internals 

• Reconciliation & React Fiber: 

	• How does React's reconciliation algorithm work, and what is its role in performance? The process involves comparing the new virtual DOM tree with the previous one to determine the minimum number of changes needed to update the actual DOM efficiently. 
	• Explain React Fiber and how it improves performance. React Fiber is a re-implementation of the core algorithm that enables incremental rendering, allowing React to pause, abort, or prioritize updates to keep the UI responsive, crucial for smooth user experiences, especially in complex applications. 

• Virtual DOM vs. Real DOM vs. Shadow DOM: Clarify the differences. The Virtual DOM is a lightweight, in-memory representation used by React for efficient updates, while the Shadow DOM is a web standard for encapsulating DOM and styling within a component. 
• Hydration: What is hydration in React, and how does it make server-rendered HTML interactive on the client side?. 
• Event Handling: How does React handle events using a synthetic event system and event delegation?. [1, 3, 4, 5, 6]
