conflictingEvent: list of eventid

handleconflict:
1. create a binary tree based on start date. 
2. earlier will go to the left and later to the right.
3. the traverse each node and store the max end date at the node by comparing its children end date with its own's end date and store that.
4. for each date search like what event is happening on that date, we will traverse based on if the event date is less than or greater than the max end date at each node.
if less check the left tree and stop when we see the max end date is less that the event date.
we then got to the right side and continue. at each node we also check if that date falls on the node date range. if yes we add it to the list.

conflictingEvent in events_map will be populated based on events tree
